Interface IGenerativeModel

Namespace
GenerativeAI
Assembly
GenerativeAI.dll

Defines the contract for a generative AI model. This interface provides methods for generating answers and content, streaming content, and counting tokens within inputs or outputs. It also includes properties for configuring behavior related to grounding, external tools, and advanced options such as JSON mode or function calling.
