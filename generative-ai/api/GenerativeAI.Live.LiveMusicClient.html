Remarks

Typical usage: ConnectAsync(bool, CancellationToken), then SetWeightedPromptsAsync(IEnumerable<WeightedPrompt>, CancellationToken) and optionally SetMusicGenerationConfigAsync(LiveMusicGenerationConfig, CancellationToken), then PlayAsync(CancellationToken). Audio arrives through AudioChunkReceived as raw 16-bit PCM (48 kHz stereo by default). Prompts and config can be changed while playing to steer the music. Live Music is only available on the Gemini API (not Vertex AI).

WebsocketClientFactory

Optional factory that ConnectAsync(bool, CancellationToken) uses to create the WebSocket client instead of the default reconnecting Websocket.Client.WebsocketClient. It receives the Live Music endpoint URL (which already contains the API key as the key query parameter) and must return a client that has not been started; ConnectAsync(bool, CancellationToken) subscribes to it and then calls Websocket.Client.IWebsocketClient.Start(). Useful for custom transports, proxies and unit testing.
