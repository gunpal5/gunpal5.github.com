PromoteOversizedAttachmentsAsync(IList<ChatMessage>, GenerativeModel, CancellationToken)

Auto-promotes a Microsoft.Extensions.AI.DataContent to the Files API when its payload exceeds Gemini's 20 MB inline_data limit. Walks the message list, uploads any oversized binary attachments via model's Files client, and rewrites those entries to point at the resulting remote file URI. Cheap when nothing is oversized — the loop just short-circuits. Call this BEFORE ToGenerateContentRequest(IEnumerable<ChatMessage>, ChatOptions?) so the converted parts use FileData instead of InlineData.
