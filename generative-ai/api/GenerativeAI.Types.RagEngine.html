VertexRagManager

VertexRagManager provides management and interaction capabilities for RAG (Retrieval-Augmented Generation) resources. It is designed to facilitate operations involving file management and RAG corpus resources. This class serves as a specialized client built upon the BaseClient, leveraging shared functionality like authorization handling and HTTP communication. The manager provides direct access to:

  • File management operations via FileManagementClient.
  • RAG corpus operations via RagCorpusClient.
