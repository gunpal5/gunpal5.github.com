Class AgentApisSerializerContext

Namespace
GenerativeAI.Types
Assembly
GenerativeAI.dll

Source-generated JSON metadata for the agent-related API types (Voices, Agents, Environments, Triggers, Credentials and Decisions). The clients of these APIs put it first in their resolver chain (followed by InteractionsSerializerContext for the shared Interactions types), so they work with Native AOT and trimming.
