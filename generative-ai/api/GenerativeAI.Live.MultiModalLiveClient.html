WebsocketClientFactory

Optional factory that ConnectAsync(bool, CancellationToken) uses to create the WebSocket client instead of the default reconnecting Websocket.Client.WebsocketClient. It receives the Live API endpoint URL from the platform adapter (which, for the Gemini API, already contains the API key) and must return a client that has not been started; ConnectAsync(bool, CancellationToken) subscribes to it and then calls Websocket.Client.IWebsocketClient.Start(). When null (the default), the client is created as before.

public Func<string, IWebsocketClient>? WebsocketClientFactory { get; set; }

Property Value

Func<string, IWebsocketClient>

Remarks

The factory is responsible for any request headers the endpoint needs. In particular, the default client adds an Authorization: Bearer header from GetAccessTokenAsync(CancellationToken) (required by Vertex AI); a custom factory must add it itself. With an ephemeral token (auth_tokens/...) as the API key, the URL is the constrained endpoint and the factory must send Authorization: Token {token} instead. This is useful for custom transports, proxies, and unit testing.

Remarks

Activity markers delimit audio input. The Gemini API rejects realtime text sent between SendActivityStartAsync(CancellationToken) and SendActivityEndAsync(CancellationToken) ("Precondition check failed"); send text with SendRealtimeTextAsync(string, CancellationToken) outside the markers instead.
