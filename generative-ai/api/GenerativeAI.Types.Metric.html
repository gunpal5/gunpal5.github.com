Remarks

Set the convenience properties (Name, PromptTemplate, JudgeModelSystemInstruction, ReturnRawOutput) and TuningClient converts them to the wire format (ExactMatchSpec, BleuSpec, RougeSpec or PointwiseMetricSpec plus AggregationMetrics) the same way the google-genai SDK does. The wire-format properties can also be set directly.
