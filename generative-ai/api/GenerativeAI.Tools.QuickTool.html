QuickTool(Delegate, string?, string?, JsonSerializerOptions?)

Represents a tool capable of wrapping a delegate function and exposing it as an interactive tool.

public QuickTool(Delegate func, string? name = null, string? description = null, JsonSerializerOptions? options = null)

Parameters

func Delegate

The delegate function to be wrapped by the tool.

name string

The name of the function for identification. Optional.

description string

A description of the function for metadata purposes. Optional.

options JsonSerializerOptions

The JSON serializer options for serialization and deserialization. If not provided, GenerateObjectJsonOptions will be used, including any custom type resolvers added to it. This can also be ignored if not using NativeAOT or Trimming

Remarks

QuickTool enables the use of delegate-based functions as tools by utilizing runtime reflection for schema generation and invocation. It is incompatible with Ahead-Of-Time (AOT) compilation scenarios and environments that require trimming support.
