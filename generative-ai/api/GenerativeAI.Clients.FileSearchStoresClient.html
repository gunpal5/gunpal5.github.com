Remarks

Typical flow: create a store with CreateFileSearchStoreAsync(string?, string?, CancellationToken), add files with UploadToFileSearchStoreAsync(string, string, UploadToFileSearchStoreConfig?, Action<double>?, CancellationToken) or ImportFileAsync(string, string, ImportFileConfig?, CancellationToken), wait for indexing with WaitForOperationAsync(FileSearchOperation, TimeSpan?, TimeSpan?, CancellationToken), then pass the store name to the FileSearch tool (for example via UseFileSearch(params string[])).

File Search is only available on the Gemini Developer API; every method throws NotSupportedException when the client is configured for Vertex AI.
