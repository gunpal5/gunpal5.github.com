Namespace GenerativeAI.Types.Converters

Classes

DateOnlyJsonConverter

JSON converter for DateOnly values, supporting ISO 8601 date formats.

LenientFinishReasonConverter

Lenient JSON converter for FinishReason that handles unknown enum values gracefully. When an unknown string value is encountered, it falls back to FinishReason.OTHER instead of throwing an exception. This prevents crashes when Google adds new FinishReason values to their API.

LenientTrafficTypeConverter

Lenient JSON converter for TrafficType that handles unknown enum values gracefully. When an unknown string value is encountered, it falls back to TRAFFIC_TYPE_UNSPECIFIED instead of throwing an exception. This prevents crashes when Google adds new TrafficType values to their API.

TimeOnlyJsonConverter

JSON converter for TimeOnly values.

VideoAspectRatioConverter

Converts a VideoAspectRatio enum to and from its string representation (e.g., "16:9", "1:1"). Converts ASPECT_RATIO_UNSPECIFIED to/from JSON null.

VideoPersonGenerationConverter

Converts a VideoPersonGeneration enum to and from its snake_case string representation.

VideoResolutionConverter

Converts a VideoResolution enum to and from its string representation (e.g., "HD_720P", "SD_480P"). Converts RESOLUTION_UNSPECIFIED to/from JSON null.
