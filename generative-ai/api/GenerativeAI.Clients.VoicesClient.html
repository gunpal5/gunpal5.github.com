Class VoicesClient

Namespace
GenerativeAI.Clients

GenerativeAI.dll

A client for the Voices API (/voices): design voices from a prompt, remix an existing voice, replicate a voice from recorded audio, and list custom and prebuilt voices for text-to-speech. Follows python-genai's client.voices.
