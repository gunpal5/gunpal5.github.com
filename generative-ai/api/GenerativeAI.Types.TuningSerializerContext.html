Remarks

This is a separate context rather than a partial of TypesSerializerContext because the System.Text.Json source generator shipped for net6.0-net10.0/netstandard2.0 fails when [JsonSerializable] attributes are split across partial declarations (duplicate hint names). TuningClient inserts it first in its serializer resolver chain. Options mirror those of TypesSerializerContext.
