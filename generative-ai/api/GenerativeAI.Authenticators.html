Namespace GenerativeAI.Authenticators

Authenticators for Google Cloud credentials: Application Default Credentials, OAuth and service accounts. The advanced authenticators are in the Google_GenerativeAI.Auth package.

Classes

BaseAuthenticator

An abstract base class for implementing authenticators for Google APIs.

GoogleCloudAdcAuthenticator

Provides a mechanism for authenticating with Google Cloud services using Application Default Credentials (ADC).

GoogleOAuthAuthenticator

Authenticator that uses Google OAuth2 for authentication with Google services.

GoogleServiceAccountAuthenticator

Authenticator that uses Google Service Account credentials for authentication with Google services.
