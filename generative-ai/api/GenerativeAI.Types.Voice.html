Class Voice

Namespace
GenerativeAI.Types

GenerativeAI.dll

A voice: a custom voice created with POST /voices (designed from a prompt or replicated from audio) or a prebuilt system voice from Google's voice catalog (returned by GET /voices). Use its Key / Id as the voice of a text-to-speech request.
