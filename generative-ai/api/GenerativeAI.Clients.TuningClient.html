Remarks

On Vertex AI it uses the projects/{project}/locations/{location}/tuningJobs resource and supports supervised fine tuning, preference tuning, distillation and reinforcement tuning, listing, cancellation and reward validation.

On the Gemini Developer API it uses the tunedModels resource: TuneAsync(string, TuningDataset, CreateTuningJobConfig?, CancellationToken), GetAsync(string, CancellationToken), CancelAsync(string, CancellationToken) and WaitForCompletionAsync(string, TimeSpan?, TimeSpan?, CancellationToken) are supported, and tuned models are reported as TuningJobs.
