GenerativeAI.dll

Response from the model supporting multiple candidate responses. Safety ratings and content filtering are reported for both prompt in PromptFeedback and for each candidate in FinishReason and in SafetyRatings. The API:

  • Returns either all requested candidates or none of them
  • Returns no candidates at all only if there was something wrong with the prompt (check PromptFeedback)
  • Reports feedback on each candidate in FinishReason and SafetyRatings.
