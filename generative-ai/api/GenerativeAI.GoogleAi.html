The GoogleAI class serves as the main entry point for interacting with Google's AI models. It provides methods to create generative and embedding models, as well as manage and retrieve model details. This class integrates Google's AI platform capabilities by utilizing appropriate models and configurations to handle generative AI tasks, embeddings, and other related operations.

CreateGeminiModel(string, GenerationConfig?, ICollection<SafetySetting>?, string?)

Creates a new instance of the GeminiModel class, configured with the specified model name, generation settings, safety settings, system instructions, and optional HTTP client and logger for enhanced AI functionality. GeminiModel provides an interface to interact with specific generative AI models on the Google AI platform, offering tailored content generation capabilities.

public GeminiModel CreateGeminiModel(string modelName, GenerationConfig? config = null, ICollection<SafetySetting>? safetyRatings = null, string? systemInstruction = null)

An optional collection of safety settings to restrict the model's output based on defined criteria.
