Remarks

The wire format follows python-genai's generated webhooks client (snake_case field and query parameter names). Requests go to {base}/{version}/webhooks on the Gemini Developer API and to {base}/{version}/projects/{project}/locations/{location}/webhooks on Vertex AI.
