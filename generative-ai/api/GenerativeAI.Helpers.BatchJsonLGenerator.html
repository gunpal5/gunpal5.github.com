Provides helper methods for generating JSONL (JSON Lines) content for batch processing. This is the centralized helper for creating batch input files for both Vertex AI and Google AI.

Remarks

JSONL format consists of JSON objects separated by newlines, with no commas between lines. Each line represents a complete JSON object suitable for batch API requests.

For Vertex AI: Use these methods to create JSONL files to upload to GCS. For Google AI: Use InlinedRequest directly with the BatchClient.

GenerateContentJsonL(IEnumerable<string>, BatchOptions?)

Generates JSONL content for batch content generation requests. This is the primary method for creating batch input files.

public static string GenerateContentJsonL(IEnumerable<string> prompts, BatchOptions? options = null)

Parameters

prompts IEnumerable<string>

List of prompt texts to process.

options BatchOptions

Optional batch options including schema, system instruction, etc.

Returns

string

A string containing properly formatted JSONL for batch prediction.

Examples

// Simple prompts without schema
var jsonl = BatchJsonLGenerator.GenerateContentJsonL(
    new[] { "What is AI?", "Explain machine learning" });

// With schema for structured output
var jsonl = BatchJsonLGenerator.GenerateContentJsonL(
    new[] { "Create profile for John, age 30" },
    new BatchOptions { ResponseSchemaType = typeof(Person) });
