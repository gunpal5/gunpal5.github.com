ModelClient(IPlatformAdapter, HttpClient?, ILogger?)

A client for interacting with the Gemini API Models endpoint, providing methods to retrieve and list available models for use with the Generative AI platform.

public ModelClient(IPlatformAdapter platform, HttpClient? httpClient = null, ILogger? logger = null)

Parameters

platform IPlatformAdapter

The platform adapter used to manage API endpoints and authentication.

httpClient HttpClient

The HTTP client instance used for making API requests.

logger ILogger

An optional logger instance for logging operations.

Remarks

The ModelClient serves as an abstraction to interact with the API's model-related endpoints. It is responsible for retrieving model metadata and listing available models on the platform.

Returns the tokens and token ids of the given contents (Vertex AI only), like models.compute_tokens of the google-genai SDK. Use CountTokensAsync of GenerativeModel to count tokens on both platforms.

The cancellation token to observe while waiting for the task to complete.

Returns

Task<ComputeTokensResponse>

The ComputeTokensResponse with the tokens info for each content.
